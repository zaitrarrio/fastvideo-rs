# Wan 3.0 (Alibaba Tongyi Wanxiang) — release status, openness, architecture and methodology, as of 2026-10-21

Research date: 2026-10-21. All "as of" statements refer to what the cited pages showed on that date. Primary sources (Alibaba Cloud blog / Model Studio help centre / Wan-AI Hugging Face / Wan-Video GitHub / arXiv) are labelled **[primary]**; everything else is **[third-party]**. Note at the outset: **Alibaba has published no technical report, paper, model card, parameter count, or architecture description for Wan 2.5, 2.6, 2.7 or 3.0.** Every architecture statement about those versions found on the web is third-party and unsourced; the only documented Wan architecture is that of the open-weight Wan 2.1 / Wan 2.2 line (and open auxiliary models built on it).

## Key question 1 — What exactly is "Wan 3.0" (release date, product name, API availability, pricing) and is there a technical report?

### Takeaway
Wan 3.0 ("Wan3.0-Video", 万相3.0, Model Studio model IDs `wan3.0-video` and `wan3.0-video-prime`) is an API-only, hosted video generation model that Alibaba put into public beta in China on 2026-08-06 and announced internationally on Alibaba Cloud Model Studio on 2026-08-13; it is still labelled "Currently in preview" in the Model Studio API reference as of its 2026-10-15 revision. There is no technical report, paper or arXiv ID for Wan 3.0; Alibaba's own posts describe only product capabilities (30-second single-pass generation at up to 1080p/30 fps with audio, "omni"/multi-reference inputs including documents and web links).

### Inferences
- The "public beta" vs "invite-only" contradiction inside Alibaba's own Chinese article suggests a staged rollout: open beta of the base generation modes from 2026-08-06, some advanced capabilities invite-only, then wider availability around 2026-08-24 (third-party). The English API reference still says "preview" as of 2026-10-15.
- Official USD pricing ($0.05/$0.10/$0.20 per s) is consistent with the CNY list price (0.3/0.6/1.2 ≈ $0.04/$0.08/$0.17) plus an international markup; 1080P output is 2x the Wan 2.6/2.7 1080P price ($0.15/s), 720P is the same ($0.10/s).
- "wan3.0-video-prime" appears to be a speed-optimised (likely distilled or fewer-step) serving variant, but Alibaba does not say how it is made.

### Gaps
- No Alibaba page states the precise release stage (beta/preview/GA) with a date in English; the beta date 2026-08-06 rests on QbitAI (Alibaba-provided content) and Alibaba's Chinese developer article.
- No technical report, arXiv ID, parameter count, or architecture statement for Wan 3.0 exists in any Alibaba source found.
- The currency of the Singapore-region prices on the Chinese developer article is unlabelled; the English blog's $0.05/$0.10/$0.20 should be treated as the authoritative international price.

## Key question 2 — Are any Wan 3.0 weights, code or derived models openly available, and under what licence?

### Takeaway
No. As of 2026-10-21 the official Wan-AI Hugging Face organisation and the Wan-Video GitHub organisation contain no Wan 3.0 (nor Wan 2.5/2.6/2.7) weights, code, model card or licence; the newest repositories are auxiliary models (Wan2.2-Animate-2-14B, Wan-Dancer-14B) that carry Wan2.2/2.1-era names. Claims on SEO sites that Wan 3.0 shipped Apache-2.0 1.3B/14B checkpoints in April 2026 are false by inspection of the official repos.

## Key question 3 — Documented architecture and training techniques of Wan 3.0 (and Wan 2.5/2.6/2.7)

### Takeaway
Alibaba has disclosed essentially nothing technical about Wan 2.5/2.6/2.7/3.0: no parameter counts, no MoE/dense statement, no VAE or text-encoder details, no post-training (RL/DPO), distillation or sparse-attention descriptions. The documented facts are product-level (duration, resolution, fps, native audio, reference inputs, "thinking mode" for images). The only Wan architecture that is fully documented remains Wan 2.1/2.2 (two-expert MoE DiT, umT5 text encoder, Wan2.2-VAE 4x16x16) and the open auxiliary models built on it.

### Cited Findings

**Wan 3.0 (Aug 2026) — product-level only**
- Single-pass up to 30 s, 30 fps, 1080P default, H.264 MP4, audio generated by default (`audio: true`), smart duration (`-1`), video extension, adaptive aspect ratio; multi-reference inputs up to 10 images + 5 videos (≤15 s total) + 5 audio clips (≤15 s total) + 1 document (≤100 MB/50 pages) + 1 web link; prompt up to 20,000 characters; "prime" high-speed variant. — [help.aliyun.com Wan3.0 API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference); [alibabacloud.com Wan3.0 API](https://www.alibabacloud.com/help/en/model-studio/wan3-video-generation-api-reference)
- Stereo (two-channel) audio output, multiple Chinese dialects, music-rhythm matching; editing of background/subject/lighting/sound; web search during generation. — [developer.aliyun.com/article/1754056](https://developer.aliyun.com/article/1754056)
- Alibaba attributes the gains to "strong prompt engineering and instruction-following that convert prompts into scheduling inputs" (QbitAI, Alibaba-provided) — the only quasi-technical statement found, and it is not an architecture description. — [QbitAI 2026-08-07](https://www.qbitai.com/2026/08/467877.html)
- Alibaba acknowledges weaknesses: "audio texture and on-screen text rendering accuracy are improving but not yet where we want them." — [Alibaba Cloud blog 2026-08-13](https://www.alibabacloud.com/blog/wan3-0-30-second-ai-video-generation-from-any-input_603452)
- **Unsourced third-party specs** circulating for Wan 3.0: "native 4K", "six-shot AI Director mode", "Identity Lock", "twelve-language lip-sync", and a specific parameter count on a community wiki — none links to an Alibaba source (Digital Applied explicitly flags these as unverified). The official API caps output at 1080P. — [digitalapplied.com](https://www.digitalapplied.com/blog/wan-3-0-reality-check-rumor-vs-shipped)

**Wan 2.7 (Apr 2026) — product-level only**
- Official announcement (Alibaba Cloud Community, 2026-04-07, originally on Alizila): suite of Wan2.7-t2v, Wan2.7-i2v, Wan2.7-r2v, Wan2.7-videoedit (Wan2.7-Image and Wan2.7-Image-Pro announced "days earlier"); 2–15 s, 720p and 1080p; "unifies text, image, video, and audio inputs into a single cohesive system"; auto lip-sync to rewritten dialogue with distinct voices; audio clips can drive scene changes (e.g. weather); ending-frame specification via video continuation; multi-panel image guidance; cross-video consistency for "up to five distinct characters"; "dozens of camera movements", "thousands of style combinations and over 50 refined emotional expressions". The only architecture language: "Trained on aligned video edits" and "a novel end-to-end architecture for precise content reconstruction". **Thinking mode is not mentioned** in this video post; no pricing; no open-source mention. — [Alibaba Cloud blog, 2026-04-07](https://www.alibabacloud.com/blog/alibaba-unveils-wan2-7-video-to-elevate-creators-from-executors-to-directors_603009)
- Model Studio `wan2.7-t2v` page (last updated 2026-10-11): snapshot IDs `wan2.7-t2v-2026-04-25` and `wan2.7-t2v-2026-06-12`; 720P/1080P tiers; audio listed as an input modality for the base/April snapshot; pricing USD 0.10/s (720P) and 0.15/s (1080P) in Singapore, 0.086012/0.143353 in Beijing/Tokyo (0.082513/0.137521 for the June snapshot). — [alibabacloud.com help: wan2.7-t2v](https://www.alibabacloud.com/help/en/model-studio/wan2-7-t2v)
- "Thinking mode" is officially documented only for the **image** API: `thinking_mode` boolean, default true, takes effect only with image-set mode off and no image input, "improves output quality but increases generation time" (example model `wan2.7-image-pro`). — [alibabacloud.com help: Wan image generation and editing API](https://www.alibabacloud.com/help/en/model-studio/wan-image-generation-and-editing-api-reference)
- Third-party coverage (tellers.ai, 2026-04-15) dates the release to 2026-04-06 (T2V available from 2026-04-03), describes video "Thinking Mode" as a planning step for composition/motion/narrative, states "the weights have not been released", and cites no official source. ABNewswire press-release copies (2026-04-06) via FinancialContent/Barchart/MarketScreener are reseller-distributed PR, not Alibaba. — [tellers.ai](https://tellers.ai/blog/wan_2_7_thinking_mode_ai_video_generation_2026-04-15); [FinancialContent/ABNewswire](https://markets.financialcontent.com/stocks/article/abnewswire-2026-4-6-alibaba-launches-wan-27-breakthrough-ai-image-and-video-generation-model-with-thinking-mode)

**Wan 2.6 (Dec 2025) — product-level only**
- Official: announced 2025-12-16 from Hangzhou; Wan2.6-R2V ("China's first reference-to-video generation model": upload a character reference video with appearance and voice, generate new scenes; subjects can be person/animal/object or several; multi-person dialogue), Wan2.6-T2V, Wan2.6-I2V, Wan2.6-image, Wan2.6-T2I; video up to 15 s; "intelligent multi-shot storytelling with visual consistency across shots"; improved audio-visual synchronisation and audio-to-video; image models support interleaved text-image output. **Wan 2.2 (Jul 2025) — the last fully documented open architecture [primary]**
- Released 2025-07-28 (inference code + weights; Diffusers and ComfyUI integration same day); Wan2.2-S2V-14B 2025-08-26 (with technical report); CosyVoice TTS for S2V 2025-09-05; Wan2.2-Animate-14B 2025-09-19; Animate in Diffusers 2025-11-13. Models: T2V-A14B and I2V-A14B (MoE, 480P/720P), TI2V-5B (dense, 720P, high-compression VAE), S2V-14B, Animate-14B. Licence Apache 2.0. — [Wan2.2 README](https://raw.githubusercontent.com/Wan-Video/Wan2.2/main/README.md)
- MoE design: two experts — a high-noise expert for early denoising steps/overall layout and a low-noise expert for later steps/fine detail; ~14B parameters each, 27B total, 14B active per step; expert switch set by a signal-to-noise-ratio threshold. — [Wan2.2 README](https://raw.githubusercontent.com/Wan-Video/Wan2.2/main/README.md)

RL/post-training: not mentioned. — [Wan2.2 README](https://raw.githubusercontent.com/Wan-Video/Wan2.2/main/README.md)

### Inferences
