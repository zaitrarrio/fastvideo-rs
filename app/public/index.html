Generate a video

curl https://engine.example.com/v1/videos \
  -H "Authorization: Bearer $FV_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "fasth3",
    "prompt": "A lighthouse in a storm, waves crashing",
    "seconds": "5",
    "size": "1280x720"
  }'

Poll until done

# POST returns {"id": "..."}. Poll:
curl https://engine.example.com/v1/videos/$ID \
  -H "Authorization: Bearer $FV_KEY"
# {"status":"completed","url":"https://.../video.mp4"}

Point the playground at your engine URL and paste your API key — keys stay in your browser, never on our servers.
